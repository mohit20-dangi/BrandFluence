About the Project
BrandFluence is a mobile application that serves as a communication and collaboration hub for influencer marketing. It empowers companies to post sponsorship campaigns and allows influencers, from nano to macro, to discover and apply for opportunities that align with their niche. The platform streamlines the entire process, from discovery and communication to campaign management, saving time and maximizing return on investment for both parties.

✨ Key Features
👤 Dual Registration: Separate and tailored registration processes for Brands and Influencers.

📝 Profile Management: Users can create and update detailed profiles. Influencers can showcase their platform metrics, audience demographics, and media kits, while brands can outline their sponsorship goals and target audience.

📢 Campaign Posting & Management: Brands can create, post, and manage detailed sponsorship campaigns, including budget, timeline, and deliverables. They can also review and approve applications from influencers.

🔍 Advanced Search & Filtering: Influencers can easily search for campaigns using filters like budget, category, and platform. Brands can search for influencers based on platform, audience size, and engagement rates.

💬 Real-time Chat: A built-in messaging system to facilitate smooth and direct communication between brands and selected influencers.

🔔 Instant Notifications: An active notification system keeps users informed about new campaigns, application statuses, and new messages.
